# Vectorisation and aliasing: case `batch`

What each compiler did with the burst loop (the line marked `// BATCH_LOOP`) in every variant, compiled as the shootout compiles it (`tools/vectorize_report.py`). For clang, `alias-blocked loads` counts the loads on the publish path that could not be hoisted or eliminated because a store may alias them. MSVC `C5002 reason 1200` is a loop-carried dependence, which is how unresolved aliasing shows there; `reason 1102` is an operation its selected instruction set cannot vectorise.

- **clang**: `clang version 22.1.8 (https://github.com/llvm/llvm-project ca7933e47d3a3451d81e72ac174dcb5aa28b59d1)`
- **msvc**: `Microsoft (R) C/C++ Optimizing Compiler Version 19.51.36246 for x64`
- **icx**: `Intel(R) oneAPI DPC++/C++ Compiler 2026.1.1 (2026.1.1.20260724)`
